32/**
33 * For each symbol to rename, from a package to prefix, whose namespace was already renamed, creates the symbol in the
34 * original namespace, renamed to the existing name, e.g. `Psr\Log\LoggerInterface` renamed to
35 * `Acme\Log\LoggerInterface`, so uses of the original name are updated.
36 *
37 * The original namespace is found by renaming forwards, not by reversing the renaming, so it works with
38 * `namespace_replacement_patterns` (whose back-references cannot be reversed) as well as `namespace_prefix`: Strauss
39 * does not edit a package's own `composer.json`, so the original namespaces in its `autoload` key are discovered, and
40 * {@see ChangeEnumerator} renames them, e.g. `Psr\Log` to `Acme\Log`. A symbol in `Acme\Log`, or a namespace within
41 * it, was already renamed from `Psr\Log`.
42 *
43 * Namespaces not in a `psr-4` or `psr-0` key, i.e. only autoloaded by `classmap` or `files`, are only recognised by
44 * removing `namespace_prefix` from their start, so are not supported with `namespace_replacement_patterns`.
45 *
