26/**
27 * `Plain` becomes `Company\Project\Plain`. With a prefix to strip, e.g. `HTMLPurifier_`, PEAR-style names have the
28 * prefix removed and their `_` separated segments become namespace segments: `HTMLPurifier_AttrDef_CSS_Color` becomes
29 * `Company\Project\AttrDef\CSS\Color`, and `HTMLPurifier` itself becomes `Company\Project\HTMLPurifier`.
30 *
31 * A short name PHP reserves, e.g. `List`, is prepended with the library name, i.e. the stripped prefix without its `_`
32 * (or the last segment of the namespace): `HTMLPurifier_HTMLModule_List` becomes
33 * `Company\Project\HTMLModule\HTMLPurifierList`. Code which builds such a name at runtime, e.g.
34 * `'HTMLPurifier_HTMLModule_' . 'List'`, must be updated by hand.
35 *
36 * Global functions and constants declared with `const` move with their file, keeping their names: into the namespace
37 * of the file's classes, or, in a file without classes, into the namespace given. Constants declared with `define()`
38 * are always global, so stay.
39 *
40 * A symbol is only moved when it is declared in one of the given paths, in a file which can gain a single
41 * `namespace` declaration: no namespace already, and every class in it moving to the same namespace. Every other
42 * symbol is marked not to rename. The edits are planned by {@see ChangePlanner}.
